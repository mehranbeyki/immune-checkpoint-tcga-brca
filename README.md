TCGA-BRCA Immune Checkpoint Analysis 🧬📊

A comprehensive bioinformatics workflow for single-cell RNA-sequencing (scRNA-seq) analysis and immune checkpoint profiling using the TCGA-BRCA dataset.

⚠️ Project Status: Work in Progress (WIP)
This repository is actively being developed.

 Some analyses, notebooks, and visualizations are still being updated and finalized.📌 
 Project OverviewThis repository contains the code and Jupyter Notebooks used to process, analyze, and visualize single-cell transcriptomics data from breast cancer patients. The primary goal is to identify, profile, and characterize immune checkpoint expressions across different cell singlets to uncover potential therapeutic insights.
 
 🛠️ Tech Stack & Tools
 Language: Python / R
 Data Versioning: DVC (Data Version Control)
 Key Libraries: Seurat / Scanpy, Pandas, Matplotlib, SciPy


 📦 Data Storage & Reproducibility
 To keep this repository lightweight, the raw and processed single-cell datasets (approx. 2 GB including .rds and .matrix.mtx.gz files) are managed via DVC and stored locally.
